# MegaCrusher

A distortion/saturation VST3 plugin built with [JUCE](https://juce.com/), featuring an animated UI with three distortion modes, bit-crusher, tone control, and real-time visualisation.


https://github.com/user-attachments/assets/27517be3-c34e-460d-bd1e-39e22bc943ed


---

## Features

- **3 distortion modes**
  - **SOFT** -- smooth tanh saturation
  - **HARD** -- hard clip (brick-wall limiter)
  - **FOLD** -- wave-folder that mirrors the signal back into range, producing complex harmonics at high drive levels
- **DRIVE** -- main gain stage (1x to 40x), controls how hard the signal is pushed into the saturator
- **TONE** -- one-pole tilt filter: counter-clockwise rolls off highs (darker), clockwise boosts highs (brighter)
- **CRUSH** -- bit-depth reducer from 16-bit (fully counter-clockwise) down to 2-bit (fully clockwise)
- **MIX** -- dry/wet blend for parallel distortion
- **OUTPUT** -- output level from -24 dB to +6 dB
- **Transfer curve display** -- live visualisation of the current saturation shape
- **Stereo VU meter** -- peak-hold bar graph with colour-coded segments
- **Animated UI** -- floating ember particles and flame effects that react to the Drive level

---

## Parameters

| Parameter | Range | Default | Description |
|-----------|-------|---------|-------------|
| Drive | 0 - 1 | 0 | Pre-saturation gain (maps to 1x - 40x) |
| Tone | 0 - 1 | 0.5 | Tilt EQ (0 = dark, 0.5 = flat, 1 = bright) |
| Crush | 0 - 1 | 0 | Bit reduction (0 = off, 1 = max crush) |
| Mix | 0 - 1 | 1 | Dry/wet blend |
| Output | 0 - 1 | 0.75 | Output gain (-24 dB to +6 dB) |
| Mode | SOFT/HARD/FOLD | SOFT | Saturation algorithm |

## Building

### Requirements

- [JUCE 8](https://juce.com/get-juce/) installed at `C:\Program Files\JUCE\`
- Visual Studio 2022 with the **Desktop development with C++** workload
- Projucer (bundled with JUCE)

### Steps

1. Open `MegaCrusher.jucer` in Projucer
2. Click **Save Project and Open in IDE** -- this regenerates the Visual Studio solution
3. In Visual Studio, select the `MegaCrusher_VST3` project, set configuration to **Release x64**, and build
4. The plugin bundle is output to:
   ```
   Builds/VisualStudio2022/x64/Release/VST3/MegaCrusher.vst3
   ```
5. Copy `MegaCrusher.vst3` to your DAW's VST3 folder (usually `C:\Program Files\Common Files\VST3\`)

> **Note:** A `Directory.Build.props` file in `Builds/VisualStudio2022/` injects `JUCE_VST3_CAN_REPLACE_VST2=0` automatically. Do not delete it -- it is required for the VST3 target to compile cleanly on JUCE 8.
